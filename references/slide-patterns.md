# Slide pattern chooser

Use the relationship in the content to choose a layout. A decorative layout cannot repair an unclear relationship.

| Content relationship | Useful page pattern |
|---|---|
| One claim supported by evidence | Conclusion title + hero metric + two or three evidence blocks |
| Before and after | Mirrored comparison or transformation bridge |
| Ordered steps | Horizontal/vertical process with native connectors |
| System components and flows | Layered architecture with labeled nodes and directional paths |
| Change over time | Timeline or native line/column chart |
| Options or trade-offs | Comparison matrix or weighted decision cards |
| Person/project profile | Structured identity block + evidence strip + selected work |
| Dense facts with no causal link | Editorial grid; consider splitting into two slides |
| Section transition | Short statement with restrained visual motif |

Avoid repeating the same card grid across an entire deck. Reuse the design language—type, color, radius, spacing—while varying the structure to match the message.

For executive audiences, lead with the conclusion and quantify impact. For technical audiences, make inputs, transformations, outputs, assumptions, and validation visible. For academic audiences, include method, evidence, and limitations without overcrowding the page.
